## Información del módulo

Módulo base de un Sistema de Planificación de Recursos Empresariales (ERP), desarrollado para gestionar datos maestros de entidades y documentos transaccionales relacionados. Permite crear, editar, eliminar y buscar registros, y adaptarse a distintos dominios mediante configuración.

## Visión del producto

Proporcionar una base ERP sencilla, reutilizable y extensible que ayude a organizar la información de negocio en un espacio de trabajo coherente. El producto busca facilitar la gestión y consulta de entidades y sus documentos asociados, y permitir la adaptación a diferentes necesidades empresariales sin modificar la lógica central.
